# EddsWorld - Projeto front-end

Este projeto foi feito com uso de Html e css sobre as paginas web e o uso de programação

## Oque foi feito

- Criação de estrutura de Html em Pagina
- Organização de conteudo em seções
- Uso de: `herdar`,`nav`,`main`,`section`,`article` e `table`
- Colocamos Banner
- fizemas esrtilização em css
- definimos cores, fontes, espaçamento e layout visual

### Estrutura do Projeto

- `index.html` - estrutura da pagina
- `style.css` - estilo e layout do site
- `imagem/` - imagens usadas no projeto
